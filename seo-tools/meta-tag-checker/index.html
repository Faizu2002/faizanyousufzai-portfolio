How it works

Check your title and meta description before publishing.

This meta title checker and meta description checker reads the HTML you paste and shows the title, description and other important tags in one place. It also works as a simple title tag checker when you only want to review the page title.

What should a good title tag do?

A title should clearly explain the page topic and give searchers a reason to click. The tool acts as a meta title length checker and SEO title checker, but length is only one part of a good title. Relevance, wording and search intent matter more than hitting an exact number.

How long should a meta description be?

There is no fixed character limit that guarantees how Google will show a snippet. As a practical guide, descriptions around 140 to 160 characters often give enough space to explain the page. The meta description length checker flags very short or long descriptions so you can review them quickly.

More than a basic metadata check

A useful SEO meta tag checker should look beyond two fields. This page also works as a lightweight meta tags checker, website meta tag checker, meta data checker and meta tag analyzer by reviewing canonical, robots, viewport, language and Open Graph metadata.

What about a Google meta title checker?

A Google meta title checker can only provide an estimate. Google may rewrite titles or descriptions based on the query and page content. Use the preview to spot obvious issues, then judge the title by clarity, relevance and how well it matches the page.

FAQ

Meta tag checker questions

Does this tool send my HTML to a server?

No. The pasted HTML is parsed inside your browser by JavaScript.

Is 60 characters a hard title limit?

No. Search engines display titles based on available space and may rewrite them. The length check is guidance for review, not a ranking rule.

Can a missing meta description hurt rankings?

A missing description does not automatically mean a page cannot rank, but a useful description can improve how the page is presented to searchers.

Why does Google show a different title or description?

Google can generate or rewrite snippets when it believes another part of the page better matches a user's query.

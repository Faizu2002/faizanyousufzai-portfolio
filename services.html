SEO service FAQ

Questions before starting an SEO project.

A few practical answers about scope, timelines and how the SEO work connects with an existing website.

What SEO services do you offer?

I work across technical SEO, on-page SEO, off-page research, SEO audits, content structure and SEO-focused web development. The exact mix depends on what is holding the website back.

What does a technical SEO service include?

It can include crawling and indexing checks, canonicals, redirects, XML sitemaps, robots.txt, structured data, internal architecture, Core Web Vitals and other technical issues affecting search visibility. You can also see my technical SEO service.

Can you improve SEO on an existing website?

Yes. Many websites can be improved without rebuilding them through technical fixes, better internal linking, on-page optimization, schema, content updates and performance improvements.

Can you handle SEO and web development together?

Yes. Combining SEO with development is useful when recommendations involve templates, navigation, markup, page speed or site structure. See my SEO-focused web development work.

How long does SEO take to show results?

There is no fixed timeline. It depends on the website, competition, existing authority, technical condition, content and how quickly search engines recrawl and reassess the changes.

Do you guarantee Google rankings?

No. Rankings depend on many factors outside any one person's control. I focus on useful, measurable work across technical quality, relevance, usability, content and authority signals.
